# JUNJA LAND — PG 사전심사 준비 자료 (초안)

작성일: 2026-11-04 · 상태: **사전 검토용 / 판매 승인 아님**  
주요 대상: 결제대행사(PG), 카드사 심사, 법률 검토자, 운영자  
본 문서는 카지노형 게임 구성을 숨기거나 우회하기 위한 자료가 아닙니다.

## 1. 서비스의 실제 구성
- 서비스명: JUNJA LAND / JUNJA GAME CLUB (정식 사업자 명칭 확인 필요)
- 온라인 게임 플랫폼이며 룰렛, 슬롯, 빅휠, 포커, 훌라, 축구 승무패형 게임, 주식·코인 시뮬레이션 및 회원 간 **무료 게임머니 송금** 기능을 포함합니다.
- 카지노형 및 스포츠 베팅형 게임에서 사용하는 `J-GOLD`는 **현금으로 충전/환전/구입할 수 없도록 유지하는 모델**로 제안합니다.
- 위 기능들은 결제 페이지가 아닌 메인 서비스에도 계속 존재하며, PG가 서비스 전체를 평가할 수 있게 모두 공개합니다.
- 결제를 검토하는 첫 단계 상품은 **양도·재판매·경매·은행 매각·대출담보·현금교환이 불가한 디지털 외형 상품**입니다.
- 선불 `J-CASH` 충전은 별도 승인 전에는 판매 대상에서 제외합니다.

## 5. 기술 및 사용자 보호 정책 (아직 출시 준비 중)
- 유료 상품은 PostgreSQL에 분리된 주문·소유권·감사 이벤트로 기록합니다.
- PG사의 서버 측 승인/취소 사실을 재조회하여 금액·통화·주문번호와 일치할 때에만 지급/회수합니다.
- 환금·회원간 전송·기존 무료 게임머니/주식/코인과의 직접·간접 교환은 차단합니다.
- 현재 기능은 **테스트 브랜치에 한정**, 운영 서버 결제 UI / API는 비활성, 결제 키 미설정.
- 테스트를 통과한 것은 계약 심사, 실결제 처리 승인 또는 실제 사용자 데이터 복구 성공을 의미하지 않습니다.
