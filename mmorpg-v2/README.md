# JUNJA MMORPG V2

기존 게임에 기능을 덧붙이는 방식은 중단하고, 이 디렉터리에서 MMORPG 기반을 새로 구축한다.

## 목표
- 모바일 우선 2D MMORPG
- 바람의나라 초기 감성에 가까운 탑다운/사선형 2D 분위기
- 드래그 이동 + PC WASD/방향키
- 퀘스트 클릭 시 자동이동/필요 시 순간이동
- 캐릭터 Paper Doll 장비 외형 시스템
- 정확한 타일 충돌/길찾기
- 필드 사냥, 드랍, 채집, 광석, 제작, 장비 등급, 강화, 스킬, 보스, 던전
- 이후 파티/거래/길드/멀티플레이 확장

## 이번 재구축 원칙
1. 캐릭터 아트 규격을 먼저 고정한다.
2. 장비는 기본 캐릭터 위에 임의로 얹지 않고 모든 방향/프레임의 앵커를 공유한다.
3. 맵은 보이는 길과 실제 충돌 영역이 반드시 일치한다.
4. 기능 완료 기준은 '작동'이 아니라 '조작감 + 시각적 일관성 + 모바일 품질'이다.
5. 한 파일에 기능을 몰아넣지 않는다. 렌더링, 입력, 월드, 전투, 데이터, 네트워크를 분리한다.

## 1차 Vertical Slice
- 시작 마을 1개
- 외곽 숲 1개
- 광산 1개
- 몬스터 5종
- NPC 6명
- 퀘스트 10개
- 채집 3종(약초/나무/광석)
- 제작 8개
- 무기 6개 / 방어구 6개
- 레벨 1~15

이 Vertical Slice가 재미와 비주얼 기준을 통과하기 전에는 콘텐츠 양을 무작정 늘리지 않는다.
