# JUNJA GAME CLUB v1.0 PRO UPDATE

이번 버전은 기능 추가보다 **실제 플레이 안정성과 게임다운 연출**을 우선한 업데이트입니다.

## 핵심 수정
- 홀덤 / 윷놀이 / 섯다 / 고스톱 AI 1인 플레이 시작 버튼 복구 및 안정화
- 기존 UI 초기화 중 누락된 요소를 직접 참조해 이후 이벤트 등록이 중단되던 문제 수정
- 홀덤 현재 패 HUD: 하이카드/원페어/투페어/트리플/스트레이트/플러시/풀하우스/포카드/스트레이트 플러시 자동 표시
- 현재 플러시/스트레이트 드로우 힌트 표시
- 슬롯 `7`을 빨간 라스베거스 스타일 심볼로 변경, 캐비닛/마키/조명 디자인 강화
- 경마 Emoji 말을 커스텀 SVG 말+기수 애니메이션으로 교체, 다리/몸통/꼬리/먼지 애니메이션 적용
- 단승 선택 말이 2위면 `PLACE BONUS x0.5` 위로금 지급
- PWA 캐시 v1.0으로 갱신하여 구버전 JS 혼재 방지
- 클라이언트 오류 감지 로그 추가

## 배포
기존 GitHub 저장소에 폴더 안 파일을 업로드하고 Commit 한 뒤 Render에서 최신 Commit을 배포합니다.
기존 `DATABASE_URL` 및 관리자 환경변수는 그대로 유지합니다.
