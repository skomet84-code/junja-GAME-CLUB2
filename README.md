# JUNJA GAME CLUB v0.5

친구끼리 링크로 접속하는 모바일 우선 웹 게임 플랫폼입니다. 게임머니는 현금 가치가 없으며 충전·환전·상품 교환 기능이 없습니다. 게임 내 채팅은 제공하지 않습니다.

## v0.5 핵심 업데이트

- 슬롯 SPIN 동작 안정화 및 캐시 충돌 방지
- 슬롯은 **3행 × 3열(3×3)** 고정
- 가로 3개 + 대각선 2개 = 총 5개 페이라인
- `7️⃣ 7️⃣ 7️⃣` 단일 페이라인 배당 **x1000**
- 세 릴이 순차적으로 멈추는 애니메이션과 당첨 라인 강조
- 텍사스 홀덤: 기존 2~6인 친구 멀티 + **J-BOT AI 1인 헤즈업**
- 윷놀이: 기존 2~4인 친구 멀티 + **J-BOT AI 1인전**
- **섯다 AI 1인전** 추가: 광땡/땡/알리/독사/구삥/장삥/장사/세륙/갑오/끗 판정
- **고스톱(맞고) AI 1인전** 추가: 48장 화투, 같은 월 맞추기, 광/열끗/띠/피 점수, GO/STOP
- 로비를 6개 게임 카드 구조로 확장하고 모드 전환 UI 추가
- 모든 게임별 사용법 가이드 확장
- 채팅 없음 / 연락처형 닉네임 방지 정책 유지
- PWA 캐시를 v0.5로 변경하고 JS/CSS URL 버전을 올려 구버전 화면 잔류 문제 완화

## Render 업데이트 순서

1. ZIP 압축을 풉니다.
2. GitHub `junja-GAME-CLUB2` 저장소에서 `Add file → Upload files`를 누릅니다.
3. `junja_game_club_v0.5` 폴더 **안의 내용물 전체**를 업로드합니다.
4. `Commit changes`를 누릅니다.
5. Render가 자동 배포하지 않으면 `Manual Deploy → Deploy latest commit`을 누릅니다.
6. `Deploy succeeded / Live` 확인 후 기존 URL을 그대로 사용합니다.
7. 모바일에 이전 버전이 남아 있으면 브라우저를 완전히 닫았다 다시 열거나 새로고침합니다. v0.5는 캐시 버전 자체를 변경했습니다.
