# JUNJA GAME CLUB v1.5

## v1.5 핵심 업데이트
- 경마 1~7번 말 원터치 선택 카드 UI
- 경마 결과판 유지: 선택마 순위, 베팅액, 지급액, 손익을 다음 경주 전까지 계속 표시

- 모바일 숫자 입력 스피너 최소화
- 기존 Neon 회원/게임머니 영구저장 구조 유지

# JUNJA GAME CLUB v1.4

## 핵심 업데이트
- 777 / JJJ 페이라인 잭팟 발생 즉시 AUTO SPIN 자동 중지
- 전체 화면 JACKPOT 연출 + 폭죽/컨페티 + 전용 사운드 효과

- 자동 SPIN 중 앱/탭을 벗어나면 안전하게 중지
- 잔액 부족 시 자동 중지 유지
- Neon 영구저장 및 기존 회원 데이터 구조 유지
