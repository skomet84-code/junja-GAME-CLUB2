# JUNJA GAME CLUB v2.2 — GRAND CASINO LIVE

v2.1의 회원/Neon 영구저장/캐릭터·상점 시스템을 그대로 유지하면서, 경마·슬롯·섯다·세븐포커를 대대적으로 확장한 버전입니다.

## v2.2 핵심 업데이트

### LIVE GRAND RACE
- 1 우니 / 2 도도 / 3 아라 / 4 돼지 / 5 햅피 / 6 신동 / 7 준자
- 모든 접속자가 같은 회차·같은 결과를 공유하는 실시간 경마
- 배팅 전에 단승/복승/쌍승 전체 배당표 확인 가능
- 복승 21조합 / 쌍승 42조합 제공
- 적중 난도를 고려해 기존보다 큰 배당 범위 적용
- 가로 레이스를 세로형(위 → 아래) 트랙으로 전면 변경
- 말/기수 SVG를 탑뷰 경주마 스타일로 리디자인하고 달리기 애니메이션 개선
- 현재 참가자/닉네임/선택마/베팅 종류를 LIVE 화면에서 표시
- AUTO 10 / 30 / 50회 연속 참여 지원
- 경기 종료 후 내 선택마 순위·지급액·손익을 유지 표시

### 777 PROGRESSIVE JACKPOT
- 모든 슬롯 이용자의 실제 낙첨금(베팅금 - 일반당첨금)의 13%를 공용 잭팟에 적립
- 메인 로비와 슬롯 화면에 공용 잭팟 금액을 실시간 표시
- 기본 잭팟 50,000,000 G
- 777 적중 시 기존 777 x1000 당첨금에 더해 누적 공용 잭팟 전액 지급
- 잭팟 지급 후 공용 적립금은 50,000,000 G로 자동 리셋
- 공용 잭팟은 `game_state`에 저장되어 서버 재시작 후에도 복원

### PREMIUM 3-CARD SEOTDA
- 1인 J-BOT 모드와 친구 1:1 멀티플레이 모두 지원
- 기본 2장 → 추가 1장 → 3장 중 1장 버리기 → 남은 2장으로 승부
- 내가 버린 카드는 상대방에게 공개
- 상대가 버린 카드도 즉시 확인 가능
- 현재 내 최고 족보와 전체 섯다 족보표를 게임 화면 옆에 표시
- READY / 턴 / 드로우 / 버리기 / 쇼다운 상태를 명확하게 표시
- 섯다 전용 고급 테이블·카드·결과 연출 적용

### MULTIPLAYER SEVEN POKER
- 기존 J-BOT 1인 세븐포커 유지
- 친구 1:1 멀티플레이 추가
- 3rd / 4th / 5th / 6th / 7th Street 진행
- CHECK / CALL / RAISE / FOLD 지원
- 상대 다운카드는 쇼다운 전까지 비공개
- POT / 스택 / 현재 스트리트 / 현재 액션 / 턴 표시
- ½ POT / MAX 레이즈 프리셋 지원

## 데이터 유지
- 기존 `users`, `stats`, `ledger`, `sessions`, `user_inventory`, `user_loadout` 데이터를 초기화하지 않습니다.
- v2.2는 공용 상태 저장을 위한 `game_state` 테이블만 안전하게 추가합니다.
- Neon `DATABASE_URL`이 정상 연결되어 있으면 기존 회원/게임머니/구매 아이템/장착 상태가 그대로 유지됩니다.

## 배포
ZIP 압축을 풀고 **폴더 안의 파일 전체**를 GitHub `junja-GAME-CLUB2` 저장소 루트에 업로드해 Commit한 뒤, Render에서 `Deploy latest commit`을 실행하면 됩니다.

Render의 `DATABASE_URL`, `ADMIN_USERNAME`, `ADMIN_PASSWORD`, `ADMIN_NICKNAME`은 그대로 유지하세요.

> JUNJA GAME CLUB의 모든 게임머니와 아이템은 게임 내부 가상 재화이며 현금 가치·현금 충전·현금 환전 기능을 제공하지 않습니다.
