# JUNJA GAME CLUB v1.2 IMPACT UPDATE

v1.2는 기존 Neon 영구저장, 관리자 계정, 멀티 READY/턴 복구 구조를 유지하면서 소셜 반응, 관리자 차감, 족보 연출, 캐릭터 UI를 강화한 안정화 업데이트입니다.

## 핵심 변경
- 텍스트 채팅 없이 6종 QUICK REACTION: 😫 답답 / ⏩ 빨리 / 😭 울음 / 😂 웃음 / 😲 놀람 / 😢 슬픔
- 반응은 방 참가자만 사용 가능, 서버 화이트리스트 검증, 4.5초 후 자동 소멸, 0.7초 쿨다운
- 관리자 차감 로직 재작성: 지급/차감 방향을 명시적으로 서버에 전달, 빠른 차감 버튼과 잔액 전액 차감 추가, 잔액 초과 차감 차단
- 홀덤 CURRENT HAND에 하이카드~스트레이트 플러시 9단계 임팩트 효과
- 슬롯 J/빨간 7 당첨 시 전용 캐비닛/심볼/당첨 배너 효과
- 섯다 족보별 단계 효과: 38광땡 > 광땡 > 장땡 > 땡 > 특수족보 > 갑오 > 끗 > 망통
- 홀덤/윷놀이/섯다/고스톱/경마에 캐릭터 얼굴 UI 보강
- PWA 캐시 v1.2로 갱신
