# JUNJA GAME CLUB v1.9 · AVATAR & ECONOMY

## 이번 업데이트 핵심
게임에서 번 G를 단순히 쌓아두는 대신 **꾸미기 → 수집 → 자랑 → 다시 플레이**로 순환시키는 CLUB ECONOMY를 추가했습니다.

### JUNJA BOUTIQUE
- 총 36개 영구 보유 아이템
- 코스튬 8종
- 프로필 프레임 5종
- 칭호 6종
- 펫 5종
- 테이블 스킨 5종
- 카드 뒷면 4종
- 추가 말풍선 팩 3종
- 가격대 100,000G ~ 50,000,000G
- 구매 즉시 게임머니 장부에 `shop_purchase`로 기록
- 이미 산 아이템 중복 구매 차단
- 보유하지 않은 아이템 장착 차단
- 구매 후 클라이언트에서 바로 장착

### 아바타 / 컬렉션
- 기존 귀여운 플레이어 얼굴 위에 코스튬, 프레임, 펫을 조합
- 프로필, 랭킹, LIVE FLOOR, 홀덤, 바카라 등 주요 플레이 화면에 장착 정보 반영
- 칭호 표시
- 보유 아이템 수에 따라 자동 컬렉터 등급 부여
  - ROOKIE / BRONZE / SILVER / GOLD / DIAMOND COLLECTOR
- 상점의 `내가 보유한 아이템만` 필터 지원

### 개인 테이블 / 카드 스킨
- 에메랄드 클래식
- 로열 레드
- 미드나잇 블랙
- 네온 베가스
- 다이아 살롱
- 홀덤 / 세븐포커 / 바카라 테이블에 개인 스킨 적용
- 포커 카드 뒷면도 옵시디언 / 루비 / 24K 골드 / 코스믹 J로 변경 가능

### 추가 말풍선 팩
기본 말풍선은 무료 유지. 상점에서 팩을 구매하고 장착하면 해당 말풍선이 LIVE FLOOR와 멀티방에 추가됩니다.
- 하이프 팩: `오늘 느낌 온다!`, `굿게임!`, `터졌다!`, `딱 맞췄다!`
- 큐트 팩: `좋아좋아!`, `찡긋~`, `한 번만...`, `박수!`
- 로열 팩: `품격 있게~`, `클래스가 다르지`, `인정!`, `왕좌는 내 자리`
- 자유 텍스트 채팅은 계속 없음

### 경제 밸런스 원칙
- 모든 아이템은 **외형 / 연출 전용**
- 아이템이 승률, 카드 확률, 배당, AI 난이도에 영향을 주지 않음
- 고액 유저가 게임머니를 소비할 수 있도록 1천만~5천만 G 럭셔리 아이템 배치
- 게임머니는 현금 가치가 없으며 충전·환전·현물/상품 교환 기능 없음
