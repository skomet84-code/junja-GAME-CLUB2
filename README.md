# JUNJA GAME CLUB v2.3 — ROYAL CASINO OVERHAUL

v2.2의 회원/Neon 영구저장/상점/캐릭터/실시간 기능을 유지하면서 윷놀이, 포커, 바카라, 빅휠, 다이사이, 슬롯, 사운드, 상점 옵션, 룰렛을 대대적으로 개편한 버전입니다.

## v2.3 핵심 업데이트

### 윷놀이 PRO
- 보드 중앙 글자/START/FINISH 안내를 축소·분리해 말판과 겹침 최소화
- O5 / O10 지름길 분기점에서 `지름길` 또는 `외곽길`을 플레이어가 직접 선택
- 윷가락 회전 시간을 늘리고 나뭇결/광택/입체 그림자/낙하 모션 적용
- 윷 말에 본인이 장착한 대표 캐릭터 얼굴이 표시됨
- 모바일에서는 보드/노드 크기를 별도로 최적화

### 홀덤 · 세븐포커 ALL WALLET TABLE
- 테이블 입장 시 고정 10만 G가 아니라 본인의 현재 보유 게임머니 전액을 테이블 스택으로 이동
- 상대방도 자기 보유머니 전액으로 입장
- 퇴장/방 종료 시 남은 스택을 다시 지갑으로 정산
- 최소 1,000G 미만이면 입장 제한

### 바카라 CINEMATIC DUEL
- 기존 1:1 무제한(낮은 잔액 유저 기준 MAX) 규칙 유지
- NO MORE BETS → PLAYER → BANKER → FINAL DRAW → 결과 공개 순서의 시네마틱 연출
- 카드 효과음/승리 효과/자동 다음 판 흐름 개선

### BIG WHEEL 3D CASINO
- Canvas 기반 실제 휠 느낌의 원형 세그먼트/골드 림/허브/포인터 디자인
- 가속 → 장시간 회전 → 감속 → 포인터 틱 연출
- AUTO 10 / 50 / 100 유지

### SIC BO GLASS DOME
- 유리 돔과 카지노 테이블 위 3D 주사위 스타일로 전면 리디자인
- 주사위가 튀고 구르고 회전한 뒤 서버 결과 눈으로 정지
- SMALL/BIG/ODD/EVEN/TRIPLE/TOTAL 및 AUTO 10/50/100 유지

### 슬롯 배당 조정
- 🍒 x2 / 🍋 x3 / 🍊 x5 / 🔔 x8 / ⭐ x10 / 💎 x20
- J 한 개 Scatter당 x30
- JJJ x800
- 777 x1000 + 공용 프로그레시브 JACKPOT 전액
- 공용 JACKPOT 기본금 50,000,000G, 실제 낙첨액 13% 적립 구조 유지

### 실시간 접속자
- 메인 로비와 헤더에 현재 ONLINE 수 표시
- 게임 LIVE FLOOR 기능 유지

### SOUND SYSTEM
- 로비/슬롯/홀덤/세븐포커/바카라/윷/섯다/맞고/경마/빅휠/다이사이/룰렛별 앰비언트 톤
- 카드/칩/주사위/윷/휠/말발굽/룰렛/잭팟/승리 효과음
- SOUND/MUTE 토글 및 설정 저장

### LUXURY PERKS
- 일부 상위 등급 장착 아이템에 작고 투명한 옵션 적용
- 슬롯 희귀심볼 가중치 보너스는 장착 합산 최대 +1%로 하드캡
- 출석 보너스는 장착 합산 최대 +5%
- 상점 카드에서 옵션 수치를 구매 전에 확인 가능
- 확률을 과도하게 깨지 않도록 효과를 작게 제한

### 캐릭터 리디자인
- 남/여 캐릭터 전반을 통일된 카지노 포트레이트 스타일로 다시 정리
- 여성 캐릭터는 헤어/눈매/액세서리/컬러 테마를 더 다양하게 분리
- 장착한 캐릭터는 프로필, LIVE FLOOR, 포커/바카라/윷 등 주요 화면에 반영

### JUNJA EUROPEAN ROULETTE
- 유럽식 싱글제로 0~36
- Canvas 기반 목재/골드 휠, 실제 포켓 배열, 반대 방향 볼 회전/감속 연출
- STRAIGHT / SPLIT / STREET / CORNER / SIX LINE / DOZEN / COLUMN / RED-BLACK / ODD-EVEN / 1-18 / 19-36
- 표준 총지급 배수: x36 / x18 / x12 / x9 / x6 / x3 / x2
- 고정 10만 상한 없음. 한 라운드 전체 베팅은 본인 현재 보유 게임머니까지 가능
- 1K~1M 및 MAX 칩 버튼, BET SLIP, UNDO/CLEAR 제공

## 데이터 유지
- 기존 회원/잔액/전적/장부/상점 구매/장착/슬롯 JACKPOT은 초기화하지 않습니다.
- Neon `DATABASE_URL` 연결을 그대로 유지하면 기존 데이터가 복원됩니다.
