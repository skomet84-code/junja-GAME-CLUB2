# JUNJA GAME CLUB v0.9

모바일 멀티 안정성과 실제 플레이 흐름을 우선 개선한 대형 안정화 업데이트입니다. v0.8의 Neon 영구 저장, 관리자 센터, 슬롯/홀덤/윷놀이/섯다/고스톱/경마 기능은 유지합니다.

## v0.9 핵심 변경

- 대부분의 게임 판돈/바이인을 **직접 숫자로 변경** 가능
  - 기본적으로 1,000G 단위
  - 슬롯 1,000~500,000G
  - 경마 1,000~2,000,000G
  - 홀덤 최대 5,000,000G 등
- 멀티 대기실에 **현재 참가자 닉네임/아바타/READY 상태** 표시
- 각 참가자가 직접 `READY` 후, 전원 준비 시 방장이 게임 시작
- 게임 진행 중 상단에 **지금 내 차례 / 상대 차례**를 크게 표시
- SSE 실시간 갱신 외에 **1.2초 폴링 백업** 추가: 모바일에서 실시간 연결이 잠깐 끊겨도 자동 복구
- 앱 새로고침/재접속 시 `/api/my-room`으로 **기존 멀티방 자동 복귀**
- 호스트 `대기실 비우기`, 진행 중 `오류 복구` 기능 추가
- 관리자 센터에서 **현재 열린 방 확인 / 특정 방 강제 종료 / 모든 WAITING 방 정리** 가능
- 슬롯 릴 애니메이션을 GPU transform 기반으로 조정해 모바일 끊김 감소
- 경마 말 이동을 layout-heavy `left` 변경에서 GPU transform 기반으로 변경
- API GET 캐시 금지 / 네트워크 timeout + GET 1회 재시도로 모바일 안정성 강화
- PWA 캐시 버전 `v09`로 교체해 구버전 파일 혼재 방지
- 윷놀이 종료 후 같은 방에서 재경기 가능(참가금 재확인/재차감)

## 개인정보 보호

게임 내 채팅 기능은 없습니다. 닉네임에는 전화번호, 이메일, URL, 주요 메신저/소셜 연락처 문자열을 제한합니다.

## 영구 저장

`DATABASE_URL`이 설정되어 있으면 Neon PostgreSQL에 계정/게임머니/전적/관리자 감사기록 스냅샷을 저장합니다.

## 배포

1. 이 폴더 내용물을 GitHub `junja-GAME-CLUB2` 저장소 루트에 업로드
2. Commit changes
3. Render가 자동 배포하지 않으면 `Manual Deploy → Deploy latest commit`
4. 기존 `DATABASE_URL`, `ADMIN_USERNAME`, `ADMIN_PASSWORD`, `ADMIN_NICKNAME` 환경변수는 그대로 유지
5. 배포 후 모바일 브라우저를 완전히 종료 후 재접속하거나 홈화면 PWA를 다시 열기
