# JUNJA GAME CLUB v1.7

## 이번 업데이트
- 말풍선에서 `눈 찔러!`, `맞지 맞지~` 제거
- 프로필에 **친구에게 게임머니 보내기** 추가
- 닉네임을 먼저 확인한 뒤 캐릭터와 닉네임을 재확인해야 전송 가능
- 1만 / 5만 / 10만 / 50만 원터치 금액 + MAX
- 서버에서 현재 보유 게임머니를 다시 검사하므로 잔액 초과 전송 불가
- 자기 자신 전송, 정지 계정 전송 차단
- 전송은 DB 트랜잭션으로 보내는 사람 차감과 받는 사람 지급을 한 번에 처리
- 양쪽 `게임머니 내역`에 보내기/받기 기록 남김
- 자유 텍스트 채팅은 계속 없음
- 기존 Neon 영구저장 구조와 회원 데이터 유지

> 게임머니는 현금 가치가 없으며 현금 충전·환전·상품 교환 기능이 없습니다.
