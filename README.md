# JUNJA GAME CLUB v2.4 — HIGH STAKES & RACE STABILITY

v2.3의 회원/Neon 영구저장/상점/캐릭터/카지노 기능을 유지하면서 **섯다·세븐포커 고액 플레이**, **섯다 연속 라운드 안정화**, **경마 대기시간·질주 애니메이션**을 집중 수정한 버전입니다.

## v2.4 핵심 업데이트

### 섯다 — 100,000G 상한 제거
- AI 1인 섯다와 친구 1:1 섯다 모두 고정 100,000G 상한 제거
- 판돈은 최소 5,000G, 1,000G 단위이며 **본인의 실제 보유 게임머니까지** 설정 가능
- 원터치 금액: 10만 / 50만 / 100만 / 500만 / MAX
- 서버에서도 보유머니를 초과한 판돈은 차단하므로 화면 조작으로 초과 베팅할 수 없음

### 섯다 — 한 판 후 멈춤/재입장 문제 개선
- AI전 결과 화면에서 `같은 판돈으로 다음 판` 버튼으로 즉시 재시작
- 멀티는 한 판 종료 후 두 명이 `다음 판 READY`를 누르면 **같은 방에서 바로 다음 판 자동 시작**
- 이전 판돈보다 한쪽 잔액이 줄어든 경우, 가능한 범위 안에서 다음 판돈을 자동으로 낮춰 방이 멈추는 상황을 줄임
- 작업 중 발견한 AI 섯다 패배 결과가 일부 상황에서 `무승부`로 표시될 수 있던 판정 버그도 수정

### 세븐포커 — 전액 스택 / 상한 없음 명확화
- 세븐포커는 기존 v2.3의 ALL WALLET 구조를 유지
- 고정 100,000G 입장 제한 없이 **각자 보유한 게임머니 전액을 테이블 스택으로 가져와 플레이**
- 퇴장/방 종료 시 남은 스택을 지갑으로 정산
- UI 문구와 PWA 캐시를 v2.4로 갱신해 구버전 10만 제한 화면이 남는 문제를 줄임

### 경마 — 훨씬 빠른 회차
- 베팅 대기: **16초 → 8초**
- 질주: **약 9초 → 6.5초**
- 결과 대기: **8.5초 → 4초**
- 전체 한 회차가 기존 약 33.5초에서 약 **18.5초** 수준으로 단축

### 경마 — 부드러운 질주 / 방향·순위 버그 수정
- `requestAnimationFrame` + GPU `translate3d` 기반으로 위치 이동
- 진행 위치에 있던 상하 왕복 흔들림을 제거해 말이 뒤로 튀는 것처럼 보이는 현상 완화
- **기존 애니메이션의 순위별 도착시간 계산이 반대로 적용될 수 있던 핵심 버그 수정**: 이제 1위가 먼저 결승선을 통과하고 뒤 순위가 차례로 도착
- 세로 트랙 기준 **머리가 아래쪽(진행 방향), 꼬리가 위쪽**이 되도록 말 SVG를 다시 구성
- 머리/주둥이/귀/갈기/몸통/뒷부분/4개 다리/꼬리/기수/고삐를 분리하고, 몸통·다리·기수·꼬리 애니메이션 속도를 완만하게 조정
- 브라우저 호환성을 위해 말/기수 SVG 색상 처리도 단순화

## 데이터 유지
- 기존 회원, 잔액, 전적, 장부, 상점 구매/장착, 슬롯 JACKPOT은 초기화하지 않습니다.
- Render의 `DATABASE_URL`과 기존 관리자 환경변수는 그대로 유지하세요.

## 배포
ZIP 압축을 풀고 **폴더 안의 파일 전체**를 GitHub `junja-GAME-CLUB2` 저장소 루트에 덮어쓴 뒤 Commit하고, Render에서 `Deploy latest commit`을 실행하세요.
