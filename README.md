# JUNJA GAME CLUB v0.1

친구들끼리 링크로 접속해 순수 가상 게임머니를 걸고 플레이하는 모바일 우선 웹 게임 플랫폼입니다.

> 게임머니는 현금 가치가 없고, 현금 충전/환전/상품 교환 기능이 없습니다.

## 이번 버전에서 실제 플레이 가능한 것

### 공통 플랫폼
- 아이디/비밀번호 회원가입 및 로그인
- 가입 웰컴머니 1,000,000 G
- 일일 출석 보너스 50,000 G
- 서버 권한형 지갑(브라우저에서 잔액 조작 불가)
- 게임머니 증감 장부 30건 조회
- 전체 보유머니 랭킹
- 모바일/PC 반응형 UI
- PWA 홈 화면 설치
- 실시간 방 새로고침(Server-Sent Events)
- 방 코드 및 모바일 공유용 초대 링크
- 방 채팅
- 한 계정의 여러 게임방 중복 참가 방지
- 서버 재시작 시 대기/홀덤 칩 에스크로 자동 복구

### 텍사스 홀덤
- 2~6인 멀티플레이
- 방별 바이인과 SB/BB 자동 산정
- 딜러 버튼 순환
- 프리플랍 / 플랍 / 턴 / 리버 / 쇼다운
- 폴드 / 체크 / 콜 / 레이즈 / 올인
- 서버 카드 셔플
- 7장 중 최강 5장 족보 판정
- 하이카드 ~ 스트레이트 플러시
- 사이드팟 계산 및 동점 분할
- 상대 홀카드 비공개, 쇼다운 시 공개
- 핸드 종료 후 현재 칩을 보유한 채 다음 핸드 가능
- 퇴장 시 현재 칩을 게임머니 지갑으로 환급

### 슬롯 머신
- 1,000 / 5,000 / 10,000 / 25,000 / 50,000 G
- 모든 릴과 당첨금 서버 판정
- 7종 심볼 / 잭팟 연출
- 스핀 수 / 승리 / 누적 손익 기록

### 윷놀이
- 2~4인 멀티플레이
- 참가금 설정
- 도/개/걸/윷/모
- 윷/모 추가 턴
- 상대 말 잡기 시 추가 턴
- 4개 말 완주
- 우승자에게 해당 방 참가금 총액 지급

### 고스톱
- 로비 카드와 확장 슬롯은 준비되어 있으나 v0.1에는 미구현입니다.
- v0.2에서 화투패 덱, 먹기 판정, 광/열끗/띠/피, 흔들기/폭탄, 고/스톱 및 정산을 별도 엔진으로 구현하는 것을 권장합니다.

## 로컬 실행

Node.js 22.5 이상이 필요합니다.

Windows: `start_windows.bat` 더블클릭

또는:

```bash
node server.js
```

브라우저에서 `http://localhost:10000`

## Render 배포

GitHub 저장소 최상위에 이 프로젝트 파일들을 그대로 업로드한 뒤 Render에서 Web Service로 연결합니다.

- Language: Docker
- Branch: main
- Root Directory: 비움
- Health Check Path: `/healthz`
- 무료 테스트는 Free 플랜 가능

배포 후 생성되는 주소가 친구들에게 보낼 게임 링크입니다.

### 중요: DB 영구 저장

현재 DB는 `DATA_DIR/club.db` SQLite입니다. 개인 PC나 영구 디스크가 붙은 서버에서는 지속 저장됩니다.
무료 Render처럼 로컬 디스크가 재시작 시 초기화될 수 있는 환경에서는 장기 운영 전 PostgreSQL로 이전하거나 영구 디스크를 연결하세요.

## 보안/게임머니 구조

- 비밀번호: Node `scrypt` 해시 + 사용자별 랜덤 salt
- 세션: 256-bit 랜덤 토큰, HttpOnly/SameSite 쿠키
- 게임머니: 모든 증감은 서버 DB에서만 수행
- 각 증감 내역은 ledger에 저장
- 홀덤/윷놀이 참가금은 room_escrow로 분리 관리
- 서버 재시작으로 방이 사라질 경우 남은 에스크로를 자동 환급
- 카드 셔플/슬롯 판정/윷 결과는 서버의 cryptographic RNG 사용
