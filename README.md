# JUNJA GAME CLUB v0.7

친구 전용 웹 게임클럽. 게임머니는 현금 가치가 없으며 충전·환전·상품 교환 기능이 없습니다.

## v0.7 핵심 업데이트
- 관리자 센터 유지: 회원 조회, 게임머니 지급/차감, 계정 중지/재개, 감사 로그
- 윷놀이 엔진 전면 개편
  - 업기: 같은 팀 말이 같은 지점에 모이면 한 묶음으로 함께 이동
  - 잡기: 상대 말/스택을 잡으면 START로 보내고 추가 던지기
  - 윷/모: 추가 던지기
  - 지름길: O5/O10 코너에 정확히 멈춘 뒤 다음 이동부터 대각선 경로 진입
  - 중앙 교차로에서 진입 경로에 따라 올바른 대각선 방향 유지
  - 개인전 2~6인, 2:2 팀전, 3:3 팀전
  - AI 1인전에도 업기/지름길/잡기 적용
  - 윷가락 4개 투척 애니메이션 강화
- 경마 추가
  - 7마리 1200m 레이스
  - 말별 스피드/지구력/막판 스퍼트/당일 컨디션
  - 단승(1등), 복승(1·2등 순서 무관), 쌍승(1·2등 순서 정확히)
  - 경주별 예상 배당 변동
  - 서버 결과 판정 + 브라우저 실시간 레이스 애니메이션
- 채팅 기능 없음 / 개인정보 보호 모드 유지
