# JUNJA GAME CLUB v0.3

친구들끼리 링크로 접속해 순수 가상 게임머니로 즐기는 모바일 우선 멀티 게임 플랫폼입니다.
게임머니는 현금 가치가 없으며 충전/환전/상품 교환 기능이 없습니다.

## v0.3 핵심 업그레이드
- 전체 로비와 게임 카드에 캐릭터 일러스트 추가
- CLUB HOST 캐릭터가 있는 메인 히어로 화면
- 상단 `? 게임방법` 버튼 추가
- 첫 접속 시 전체 게임 튜토리얼 자동 표시
- 슬롯 / 홀덤 / 윷놀이별 독립 사용설명서
- 윷놀이 화면 전면 리디자인
  - 실제 보드게임 느낌의 대형 윷판
  - START / FINISH 말 보관함
  - 플레이어별 캐릭터 말 표시
  - 현재 차례 강조
  - 윷가락 4개 애니메이션
  - 도/개/걸/윷/모 결과 표시
  - 말 선택 UI 개선
  - 상대 말 잡기 이벤트 배너
  - 추가턴 안내
- 슬롯 v0.2의 3x3 / 5 paylines / 고배당 구조 유지
- PWA 캐시 버전을 v0.3으로 갱신해 업데이트 반영 개선

## 현재 플레이 가능
- 회원가입 / 로그인
- 순수 가상 게임머니 및 장부
- 출석 보너스
- 3x3 슬롯 머신
- 2~6인 텍사스 홀덤
- 2~4인 윷놀이
- 실시간 방 / 초대 링크 / 채팅 없는 개인정보 보호 모드
- 모바일 PWA

## 실행
Node.js 22 이상에서:

```bash
node server.js
```

기본 포트는 10000입니다.
Windows에서는 `start_windows.bat`을 사용할 수 있습니다.

## 배포
Render에서 GitHub 저장소를 연결한 기존 Web Service를 그대로 사용하면 됩니다.
GitHub 저장소에 새 버전을 Commit하면 자동 배포됩니다.
