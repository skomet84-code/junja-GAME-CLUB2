JUNJA GAME CLUB v0.8 - 영구 저장 설정

1) Neon 프로젝트에서 Connect -> Connection string 복사
2) 이 v0.8 파일을 GitHub junja-GAME-CLUB2 저장소에 업로드/Commit
3) Render -> JUNJA GAME CLUB -> junja-GAME-CLUB -> Environment
4) Environment Variables에 추가:
   KEY: DATABASE_URL
   VALUE: Neon에서 복사한 postgresql://... 전체 문자열
5) 기존 ADMIN_USERNAME / ADMIN_PASSWORD / ADMIN_NICKNAME은 그대로 유지
6) Save, rebuild, and deploy
7) 배포 로그에서 다음 문구 확인:
   [PERSIST] Neon connected but no previous snapshot exists yet.
   또는
   [PERSIST] Restored ... rows from Neon.
8) 첫 배포에서는 새 계정을 한 번 만든 뒤 로그아웃/재접속 테스트
9) Render가 15분 이상 잠든 뒤 다시 접속해 계정이 유지되면 성공

주의:
- DATABASE_URL은 비밀번호가 포함된 비밀값입니다. GitHub, 채팅, 스크린샷에 노출하지 마세요.
- 기존 Render 무료 SQLite에서 이미 사라진 계정 데이터는 자동 복구할 수 없습니다.
